# Operación Polizón

Juego de bioseguridad antártica del proyecto PRISMA (ANID – SCIA Anillos ATE250059), Universidad de Talca. Hecho para FestiCiencia UTalca 2026.

- Juego: abrir `index.html` (o la página publicada).
- Pantalla del stand: añadir `#tv` al final del enlace.
- Versión para charlas: añadir `#charla`.
- Conteo de jugadas del navegador (solo equipo): añadir `#datos`.

Las fotos y dibujos tienen sus créditos dentro del juego. No se guardan nombres ni datos personales.
